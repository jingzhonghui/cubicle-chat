# CubicleChat 代码结构文档

## 1. 项目概述

**CubicleChat** 是一个基于 Electron + React 的局域网即时通讯工具，支持：

- UDP 广播自动发现局域网内用户
- 点对点文字消息收发
- 消息状态（发送中/已发送/已送达）
- 消息撤回
- 系统托盘运行
- 本地 SQLite 数据存储

### 技术栈

| 类别 | 技术 |
|------|------|
| 桌面框架 | Electron 29 |
| 前端框架 | React 18 + TypeScript 5 |
| 状态管理 | Zustand 4 |
| 样式方案 | Tailwind CSS 3 + CSS 变量 |
| 构建工具 | electron-vite 2 |
| 数据库 | better-sqlite3 |
| 日志 | electron-log 5 |
| 打包工具 | electron-builder |

## 3. 核心模块详解

### 3.1 主进程（Main Process）

#### `src/main/index.ts` - 应用入口

**职责**：
- 创建 BrowserWindow 窗口
- 创建系统托盘（Tray）
- 注册 IPC 处理器
- 初始化 NetworkService 和 DatabaseService
- 窗口控制（最小化/最大化/关闭）

**关键变量**：
```typescript
let mainWindow: BrowserWindow | null = null  // 主窗口
let tray: Tray | null = null                  // 系统托盘
let networkService: NetworkService | null = null  // 网络服务
let databaseService: DatabaseService | null = null  // 数据库服务
```

**IPC 通道列表**：
| 通道 | 类型 | 说明 |
|------|------|------|
| `window:minimize` | send | 最小化窗口 |
| `window:maximize` | send | 最大化/还原窗口 |
| `window:close` | send | 关闭窗口（隐藏到托盘） |
| `window:isMaximized` | invoke | 获取窗口最大化状态 |
| `user:getInfo` | invoke | 获取当前用户信息 |
| `user:updateInfo` | invoke | 更新用户信息 |
| `user:getOnlineUsers` | invoke | 获取在线用户列表 |
| `conversation:getList` | invoke | 获取会话列表 |
| `conversation:create` | invoke | 创建会话 |
| `message:getHistory` | invoke | 获取消息历史 |
| `message:send` | invoke | 发送消息 |
| `message:withdraw` | invoke | 撤回消息 |
| `settings:get` | invoke | 获取设置 |
| `settings:set` | invoke | 设置值 |

#### `src/main/network/NetworkService.ts` - UDP 网络服务

**职责**：
- UDP 广播发现局域网用户
- 发送心跳维持在线状态
- 收发消息（文本、撤回、ACK）
- 用户状态同步

**常量配置**：
```typescript
const UDP_PORT = 2425           // UDP 广播端口
const TCP_PORT = 2426           // TCP 端口（预留）
const HEARTBEAT_INTERVAL = 30000  // 心跳间隔（30秒）
const HEARTBEAT_TIMEOUT = 90000  // 心跳超时（90秒）
const MAGIC = 'CCHT'            // 协议魔数
const VERSION = 1               // 协议版本
```

**数据包类型（PacketType）**：
| 类型 | 说明 |
|------|------|
| `ONLINE` | 上线广播 |
| `ONLINE_ACK` | 上线响应 |
| `HEARTBEAT` | 心跳保活 |
| `OFFLINE` | 下线通知 |
| `TEXT` | 文本消息 |
| `TEXT_ACK` | 消息送达确认 |
| `WITHDRAW` | 消息撤回 |
| `STATUS_CHANGE` | 状态变更 |
| `TYPING` | 正在输入 |

**UdpPacket 数据包结构**：
```typescript
interface UdpPacket {
  magic: 'CCHT'      // 魔数验证
  version: number    // 协议版本
  type: PacketType   // 消息类型
  msgId: string      // 消息唯一ID
  timestamp: number  // 时间戳
  from: {
    userId: string
    nickname: string
    ip: string
    port: number
    avatar?: string
    status: UserStatus
    version: string
  }
  payload?: Record<string, unknown>  // 负载数据
}
```

**公开方法**：
- `init()` - 初始化 UDP Socket、启动心跳
- `getOnlineUsers()` - 获取在线用户列表
- `sendMessage(data)` - 发送消息
- `withdrawMessage(messageId, conversationId)` - 撤回消息
- `updateStatus(status)` - 更新在线状态
- `sendTyping(to, isTyping)` - 发送正在输入状态
- `sendOffline()` - 发送下线通知
- `destroy()` - 清理资源

### 3.2 预加载脚本（Preload）

#### `src/preload/index.ts` - IPC Bridge

**职责**：在渲染进程中安全暴露主进程 API

**API 接口**：
```typescript
interface ElectronAPI {
  send(channel: string, data?: unknown): void           // 发送单向消息
  invoke<T>(channel: string, data?: unknown): Promise<T>  // 调用并等待响应
  on(channel: string, callback): () => void               // 监听事件
  removeListener(channel: string, callback): void         // 移除监听
}
```

**类型定义**（导出给渲染进程使用）：
- `ElectronAPI` - API 接口
- `UserInfo` - 用户信息
- `OnlineUser` - 在线用户
- `Conversation` - 会话
- `Message` - 消息

## 4. 数据流

### 4.1 消息发送流程

```
渲染进程 (React)
    │
    │  window.electronAPI.invoke('message:send', data)
    ▼
预加载脚本 (preload)
    │
    │  ipcRenderer.invoke(channel, data)
    ▼
主进程 (main)
    │
    │  networkService.sendMessage(data)
    ▼
NetworkService
    │
    │  UDP 广播到 <动态计算的子网广播地址>:2425
    ▼
目标用户
```

### 4.2 消息接收流程

```
NetworkService
    │
    │  收到 UDP 数据包
    ▼
解析数据包 → 判断 type
    │
    ├── TEXT → DatabaseService.saveMessage()
    │        └── mainWindow.webContents.send('msg:receive')
    │
    └── TEXT_ACK → mainWindow.webContents.send('msg:ack')
           │
           ▼
渲染进程 (messageStore.addMessage / updateMessageStatus)
```

### 4.3 状态更新流程

```
主进程事件（用户上线/下线/消息到达）
    │
    ▼
webContents.send() → 预加载脚本
    │
    ▼
window.electronAPI.on() → Zustand Store
    │
    ▼
React 组件自动重新渲染
```

## 5. 开发指南

### 5.1 添加新的 IPC 通道

**1. 在 `src/preload/index.ts` 添加通道**：
```typescript
// invokeChannels 或 sendChannels
const invokeChannels = [
  // ... 现有通道
  'custom:action'
]

// 如果需要接收主进程推送
const receiveChannels = [
  // ... 现有通道
  'custom:event'
]
```

**2. 在 `src/main/index.ts` 注册处理器**：
```typescript
ipcMain.handle('custom:action', async (_, data) => {
  // 处理逻辑
  return result
})

// 或单向消息
ipcMain.on('custom:notification', (_, data) => {
  // 处理逻辑
})
```

**3. 在渲染进程使用**：
```typescript
// 调用主进程
const result = await window.electronAPI.invoke('custom:action', data)

// 监听事件
window.electronAPI.on('custom:event', (data) => {
  console.log('收到事件:', data)
})
```

## 8. 注意事项

1. **安全性**：所有 IPC 通信必须经过 preload 脚本的白名单验证
2. **类型安全**：主进程和渲染进程共享类型定义在 `preload/index.ts`
3. **状态管理**：渲染进程状态存储在 Zustand 中，主进程数据通过 IPC 同步
4. **网络协议**：UDP 广播使用固定端口 2425，协议版本为 1；广播地址根据本机网络接口动态计算（IP | ~netmask），支持跨网段发现
5. **窗口控制**：按钮区域必须使用 `.no-drag` 类避免拖拽冲突
