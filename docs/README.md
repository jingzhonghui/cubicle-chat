# CubicleChat — 局域网即时通讯工具

> 轻量、跨平台、零依赖的局域网聊天软件，灵感来自飞秋（FeiQ）。

## 已实现功能

- ✅ **自动发现**：UDP 广播自动发现局域网内在线用户
- ✅ **即时通讯**：点对点文本消息收发，支持 Emoji
- ✅ **文件传输**：TCP 分块传输，**自动接受**，支持**渐变色进度条**和 MD5 校验
- ✅ **图片传输**：支持 PNG/JPG/GIF/WebP/BMP，带缩略图预览，**双击查看大图**
- ✅ **文件拖拽/粘贴发送**：支持将文件拖拽或粘贴到输入框直接发送
- ✅ **消息状态**：发送中/已发送/已送达状态指示
- ✅ **消息撤回**：2分钟内可撤回消息
- ✅ **消息历史**：本地 SQLite 持久化存储
- ✅ **会话管理**：右键删除会话或清空列表
- ✅ **多端支持**：Windows、macOS、Linux
