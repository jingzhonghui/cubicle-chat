# UI/UX 设计规范

**版本**：v1.0  
**日期**：2026-04-17

---

## 1. 设计理念

CubicleChat 的 UI 设计遵循以下原则：

- **内容优先**：界面服务于对话，不抢戏
- **信息密度适中**：紧凑但不拥挤，适合长时间使用
- **嵌入式面板**：功能通过侧边栏和内嵌面板展示，**严禁弹窗**
- **图标 + 文字标签**：功能入口同时显示图标和文字，降低认知负担
- **圆角风格**：统一使用 8px / 12px 圆角，柔和而专业
- **轻量动效**：交互反馈通过微动效实现，不使用大段过场动画

## 2. 布局结构

### 2.1 整体三栏布局

```
┌─────────────────────────────────────────────────────────────┐
│  标题栏（无边框自定义，含拖拽区、窗口控制按钮）               │  32px
├──────┬──────────────────┬────────────────────────────────────┤
│      │                  │                                    │
│ 导   │   会话列表        │         聊天内容区                 │
│ 航   │   (240px)        │         (flex-1)                   │
│ 栏   │                  │                                    │
│      │  ┌────────────┐  │  ┌────────────────────────────┐   │
│ 48px │  │搜索框      │  │  │ 对话顶栏（对方昵称+操作）    │   │
│      │  └────────────┘  │  ├────────────────────────────┤   │
│  ●   │                  │  │                            │   │
│  ●   │  会话项            │  │  消息列表（虚拟滚动）       │   │
│  ●   │  (每项 64px)      │  │                            │   │
│  ●   │                  │  │                            │   │
│  ●   │                  │  ├────────────────────────────┤   │
│      │                  │  │ 输入框区域（自适应高度）     │   │
└──────┴──────────────────┴────────────────────────────────────┘
```

### 2.2 导航栏（左侧，48px 宽）

图标导航，垂直排列，无文字标签（悬浮时 Tooltip 显示）：

| 位置 | 图标 | 功能 |
|------|------|------|
| 顶部 | 头像 | 点击打开个人资料面板 |
| 中部 | 聊天气泡 | 会话列表（默认激活） |
| 中部 | 人物组 | 联系人/在线用户列表 |
| 中部 | 文件夹 | 文件传输记录 |
| 底部 | 设置齿轮 | 设置面板 |

### 2.3 响应式窗口

| 窗口宽度 | 布局 |
|---------|------|
| < 640px | 单栏（会话列表 或 聊天区，切换） |
| 640-900px | 双栏（导航 + 聊天区，无会话列表） |
| ≥ 900px | 三栏完整布局 |

**最小窗口尺寸**：320 × 480 px  
**默认窗口尺寸**：1024 × 680 px  
**记忆窗口位置和尺寸**：应用重启后恢复

## 3. 设计令牌（Design Tokens）

### 3.1 颜色系统

```css
/* 亮色主题（默认） */
:root {
  /* 背景层级 */
  --bg-base:        #F5F5F5;   /* 应用最底层背景 */
  --bg-surface:     #FFFFFF;   /* 卡片、面板 */
  --bg-elevated:    #FAFAFA;   /* 悬浮、弹出 */
  --bg-input:       #F0F0F0;   /* 输入框背景 */

  /* 强调色（蓝绿） */
  --accent:         #2D7DD2;   /* 主要操作按钮、自己发送的消息气泡 */
  --accent-light:   #E8F1FB;   /* 轻量强调背景 */
  --accent-hover:   #2568B8;

  /* 文字 */
  --text-primary:   #1A1A1A;
  --text-secondary: #6B7280;
  --text-disabled:  #9CA3AF;
  --text-on-accent: #FFFFFF;
```

### 3.2 间距系统

```
4px   xs    极小间距（图标与文字）
8px   sm    小间距（元素内部）
12px  md    中等间距（组件内部分隔）
16px  lg    标准间距（组件间距）
24px  xl    大间距（区块间距）
32px  2xl   超大间距（页面边距）
```

### 3.3 圆角系统

```
4px   rounded-sm    小元素（标签、Badge）
8px   rounded       普通组件（输入框、按钮）
12px  rounded-lg    卡片、会话项
16px  rounded-xl    模态、面板
9999px rounded-full 头像、状态点、气泡（消息气泡使用不对称圆角）
```


## 4. 核心组件规范

### 4.1 消息气泡

```
他人消息（左对齐）：
┌──────────────────────────────────┐
│ [头像]  [昵称]          [时间]   │
│         ┌─────────────────────┐  │
│         │  消息内容            │  │
│         └─────────────────────┘  │
│                          [✓✓]   │
└──────────────────────────────────┘

自己的消息（右对齐）：
┌──────────────────────────────────┐
│         [时间]          [昵称]   │
│  ┌─────────────────────┐         │
│  │  消息内容            │[头像]   │
│  └─────────────────────┘         │
│  [✓✓]                            │
└──────────────────────────────────┘
```

**气泡样式规范：**
- 自己发的消息：背景 `var(--accent)`，文字 `white`，右侧圆角改为 `4px`
- 他人消息：背景 `var(--bg-surface)`，边框 `1px solid var(--border)`，左侧圆角改为 `4px`
- 最大宽度：聊天区宽度的 70%
- 内边距：`8px 12px`

**图片消息气泡：**
- 缩略图最大尺寸：240×240px
- 圆角：8px
- 点击放大到原始尺寸（内嵌图片查看器，不弹窗）

**文件消息气泡：**
```
┌────────────────────────────────┐
│  [📄图标]  文件名.pdf           │
│            1.2 MB              │
│  ─────────────────────────     │
│  [下载] 或 [打开文件夹]          │
└────────────────────────────────┘
```

### 4.2 会话列表项

```
┌────────────────────────────────────┐
│ [头像 40px]  昵称          [时间]  │
│              最新消息摘要   [3]     │  64px
└────────────────────────────────────┘
```

- 头像：40×40px 圆形，左下角有 8px 状态指示点
- 昵称：`text-base font-medium`，溢出省略
- 摘要：`text-sm text-secondary`，最多 1 行
- 未读角标：红色圆形，数字 > 99 显示 "99+"
- 激活状态：背景 `var(--accent-light)`，左侧 `3px` 蓝色竖线

### 4.3 输入框区域

```
┌────────────────────────────────────────────────┐
│ [📷] [📎] [😊]  [GIF]               [清空]     │  工具栏 36px
├────────────────────────────────────────────────┤
│                                                │
│  在此输入消息...                                │  输入区（min 80px）
│                                                │
├────────────────────────────────────────────────┤
│                              [Enter 发送]       │  32px
└────────────────────────────────────────────────┘
```

- 输入框：`contenteditable div`，支持粘贴图片
- 工具栏图标：24px，悬浮时背景变灰（`rounded-md`）
- 发送按钮：Ctrl+Enter 换行，Enter 发送（可在设置中切换）
- "正在输入..." 提示：显示在输入框顶部，3 秒后消失

### 4.4 在线用户列表

按状态分组，收缩展开，用户项：

```
[状态点] 昵称             [发消息按钮（悬浮显示）]  40px
```

### 4.5 头像

- 无头像时显示彩色字母头像（取昵称首字，背景色从 8 种预设中按哈希选取）
- 颜色预设（低饱和度）：
  `#E8A4A4` `#A4C8E8` `#A4E8B8` `#E8D0A4` `#C4A4E8` `#A4E8E0` `#E8C4A4` `#A4A4E8`

## 5. 关键交互规范

### 5.1 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 发送消息 |
| `Shift+Enter` | 输入框换行 |
| `Ctrl+F` | 搜索历史消息 |
| `Ctrl+,` | 打开设置 |
| `Esc` | 关闭当前面板/搜索 |
| `Ctrl+Tab` | 切换到下一个会话 |
| `Ctrl+Shift+Tab` | 切换到上一个会话 |
| `F11` | 全屏切换（暂不支持） |

### 5.2 拖放支持

- 将文件/图片拖放到聊天区域 → 高亮显示拖放区域 → 松开触发发送确认
- 将文件拖放到用户头像上 → 打开与该用户的对话并触发发送

### 5.3 右键菜单

消息气泡右键菜单（内嵌，不弹窗）：

```
复制文本
引用回复
───────
撤回（2分钟内）
转发给...
───────
复制消息 ID（开发调试用）
```

### 5.4 状态变更

- 应用最小化到任务栏/托盘：收到消息时图标闪烁
- 收到消息时：系统通知 + 会话未读角标递增

## 6. 空状态与加载状态

### 6.1 空状态

| 场景 | 显示内容 |
|------|---------|
| 无会话列表 | 图标 + "从右侧在线用户列表开始第一次对话" |
| 无在线用户 | 图标 + "等待局域网内的小伙伴上线..." |
| 无历史消息 | "你们还没有聊天记录，说个\"Hi\"吧！" |
| 无文件记录 | 图标 + "还没有传输过文件" |
| 搜索无结果 | "未找到包含 \"xxx\" 的消息" |

### 6.2 骨架屏

消息列表加载时显示骨架屏（3 个虚假消息气泡，灰色 shimmer 动画）。

### 6.3 错误状态

- 消息发送失败：气泡右侧显示红色感叹号 + "重试" 按钮
- 文件传输失败：进度条变红 + 错误原因文字 + "重试" 按钮
- 网络断开：顶部黄色横幅 "无法连接到局域网，请检查网络..."

## 7. 动效规范

遵循"有意义的微动效"原则：

| 场景 | 动效 | 参数 |
|------|------|------|
| 新消息出现 | 淡入 + 向上滑动 | 150ms, ease-out |
| 会话切换 | 交叉淡入 | 100ms |
| 侧边面板展开 | 横向展开 | 200ms, ease-in-out |
| 状态指示点变色 | 颜色过渡 | 300ms |
| 按钮悬浮 | 背景色变化 | 100ms |
| 按钮点击 | scale(0.97) | 80ms |
| 消息撤回 | 淡出并显示"消息已撤回" | 200ms |
| 文件传输进度条 | 宽度动画 | linear |

**禁止事项：**
- 不使用超过 300ms 的长动画
- 不对列表滚动添加惯性以外的动画
- 不使用视差、3D 翻转等复杂效果
