# CubicleChat 更新日志

## v1.0.0 (2026-04-21)

### 新增功能

#### 1. 会话列表右键菜单智能显示
- **功能描述**：根据点击位置自动显示对应的右键菜单选项
  - 点击**会话项**：显示"🗑️ 删除会话"
  - 点击**空白处**：显示"🧹 清空列表"
- **实现文件**：`src/renderer/src/components/layout/Sidebar.tsx`

#### 2. 聊天输入框发送按钮
- **功能描述**：在输入框底部添加"发送"按钮
  - 支持 **Enter 快捷键** 发送
  - 支持 **点击发送按钮** 发送
  - 按钮在输入为空时自动禁用
- **实现文件**：`src/renderer/src/components/layout/ChatArea.tsx`

#### 3. 网络接口选择
- **功能描述**：支持多网卡环境下手动选择网络接口
  - 设置 → 网络设置 中可查看可用网络接口
  - 支持显示/隐藏虚拟网卡（VMware/Docker/VPN 等）
  - 切换网卡后自动重新广播发现用户
- **实现文件**：
  - `src/main/network/NetworkService.ts`
  - `src/renderer/src/components/layout/SettingsPage.tsx`

#### 4. 自定义广播地址
- **功能描述**：支持添加自定义广播地址
  - 用于跨网段或特殊网络环境下的用户发现
  - 支持添加、删除自定义广播地址
- **实现文件**：`src/main/network/NetworkService.ts`

### Bug 修复

#### 1. 修复"用户不在线"错误提示
- **问题描述**：即使用户显示在在线列表中，发送消息时仍提示"用户不在线"
- **问题原因**：`onlineUsers` Map 使用 MAC 地址作为键，但查找时使用了 userId
- **修复方案**：
  - 添加 `findUserByUserId()` 辅助方法
  - 更新 `sendMessage()`、`sendFile()`、`startFileSend()` 使用新方法查找用户
- **修复文件**：`src/main/network/NetworkService.ts`

#### 2. 修复右键菜单类型定义
- **问题描述**：`SessionItem` 的 `onContextMenu` 类型定义与父组件传递的函数签名不匹配
- **修复文件**：`src/renderer/src/components/layout/Sidebar.tsx`

#### 关键修复代码
```typescript
// 新增方法：通过 userId 查找用户
private findUserByUserId(userId: string): OnlineUser | undefined {
  for (const user of this.onlineUsers.values()) {
    if (user.userId === userId) {
      return user
    }
  }
  return undefined
}
```
