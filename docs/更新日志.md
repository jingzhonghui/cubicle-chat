# CubicleChat 更新日志

## v1.0.0 (2026-04-28)

### Bug 修复

#### 1. 修复用户离线时会话状态未正确更新问题
- **问题描述**：当用户A不在线时，会话列表中A的会话状态依然显示在线状态
- **问题原因**：
  - 用户离线时，`userStore` 从在线用户列表中移除了该用户，但 `messageStore` 中的会话列表 `targetStatus` 没有被同步更新
  - `Sidebar` 组件直接渲染会话列表，没有根据 `onlineUsers` 实时判断对方状态
- **修复方案**：
  - 主进程 `user:offline` 事件中增加 `userId` 字段，方便渲染进程定位会话
  - `messageStore` 新增 `user:offline` 事件监听，将匹配 `targetId` 的会话 `targetStatus` 设置为 `'offline'`
  - `Sidebar` 渲染会话列表时，根据 `onlineUsers` 动态计算并覆盖 `targetStatus`
  - 对方重新上线时，`user:online` / `user:update` 事件正常更新状态
- **修复文件**：
  - `src/main/network/NetworkService.ts`
  - `src/renderer/src/store/messageStore.ts`
  - `src/renderer/src/store/userStore.ts`
  - `src/renderer/src/components/layout/Sidebar.tsx`

#### 2. 修复离线用户消息输入框未置灰禁用问题
- **问题描述**：对方离线时，消息输入框仍可输入和发送消息
- **问题原因**：`ChatArea` 未判断对方是否在线，也未将状态传递给 `MessageInput`
- **修复方案**：
  - `ChatArea` 通过 `onlineUsers` 实时计算 `isTargetOnline`
  - 给 `MessageInput` 传入 `disabled={!isTargetOnline}`
  - 输入框顶部增加离线提示条："对方已离线，暂时无法发送消息"
  - 输入框 `placeholder` 在离线时显示提示文字
  - 工具栏按钮（截图/图片/文件/表情/清空）全部增加 `disabled` 状态及置灰样式
  - `ChatHeader` 状态根据 `isTargetOnline` 动态显示（在线显示实际状态，离线显示 `offline`）
- **修复文件**：
  - `src/renderer/src/components/layout/ChatArea.tsx`

## v1.0.0 (2026-04-23)

### 新增功能

#### 1. 文件传输记录删除功能
- **功能描述**：在文件传输记录页面添加删除功能，支持单个删除和批量删除
  - 单个删除：点击文件记录上的 🗑️ 按钮删除单条记录
  - 批量删除：点击"批量选择"进入批量模式，可勾选多个文件进行批量删除
  - 删除确认对话框提供"同时删除本地文件"勾选框
  - 批量删除时显示选中文件数量
- **实现文件**：
  - `src/renderer/src/components/layout/FileRecordsPage.tsx` - 添加删除功能和批量选择模式
  - `src/main/database/DatabaseService.ts` - 添加 `deleteFile()` 和 `getFilePath()` 方法
  - `src/main/index.ts` - 添加 `file:delete` IPC 处理程序
  - `src/preload/index.ts` - 添加 `file:delete` IPC 通道

#### 2. 修复 Ctrl+V 发送图片重复消息问题
- **问题描述**：使用 Ctrl+V 发送图片时，接收端会显示两条重复的图片消息
- **问题原因**：`autoAcceptFile` 方法每次收到 `FILE_NOTIFY` 都会生成新的 `messageId`，如果同一个文件传输由于网络原因被处理多次，就会产生重复消息
- **修复方案**：
  - 使用 `transferId` 作为消息ID（同一个文件传输的 `transferId` 是唯一的）
  - 在保存消息前检查是否已存在相同 `fileId` 的消息
  - 添加 `getMessageByFileId()` 方法用于去重检查
- **修复文件**：
  - `src/main/network/NetworkService.ts`
  - `src/main/database/DatabaseService.ts`

### 技术细节

#### 新增 IPC 通道
```typescript
// 文件删除相关
'file:delete'  // 删除文件传输记录，参数: { fileId, deleteLocalFile? }
```

#### 批量删除流程
```
1. 用户点击"批量选择"按钮进入批量模式
2. 勾选需要删除的文件（或点击全选）
3. 点击"批量删除"按钮
4. 弹出确认对话框，可选择是否同时删除本地文件
5. 点击"删除"执行批量删除
6. 删除完成后刷新列表并显示结果
```

## v1.0.0 (2026-04-22)

### 新增功能

#### 1. 截图功能
- **功能描述**：在聊天窗口工具栏添加截图按钮，支持快速截取屏幕
  - 点击工具栏截图按钮或按 `Ctrl+Alt+A` 快捷键启动截图
  - 默认矩形选区工具，直接拖动即可创建选区
  - 编辑工具：矩形框、箭头、画笔、马赛克、文字标注
  - 8种预设颜色
  - 撤销功能（Ctrl+Z）
  - ESC 取消截图
  - 截图完成后自动复制到剪贴板并发送到当前聊天会话
- **实现文件**：
  - `src/main/services/ScreenshotService.ts` - 截图服务
  - `src/renderer/src/components/screenshot/ScreenshotWindow.tsx` - 截图选区窗口组件
  - `src/renderer/src/components/layout/ChatArea.tsx` - 添加截图按钮
  - `src/renderer/src/App.tsx` - 支持截图模式路由

### 技术细节

#### 新增 IPC 通道
```typescript
// 截图相关
'screenshot:start'       // 启动截图
'screenshot:cancel'      // 取消截图
'screenshot:capture'     // 发送截图数据
'screenshot:complete'    // 截图完成回调
```

#### 截图流程
```
1. 用户点击截图按钮 → screenshot:start
2. 主进程隐藏主窗口，捕获全屏截图
3. 创建全屏截图窗口加载截图界面
4. 用户选择区域并编辑
5. 点击完成 → screenshot:capture
6. 截图保存到临时目录 + 复制到剪贴板
7. 通知主窗口 → screenshot:complete
8. 截图自动发送到当前聊天会话
```

#### 全局快捷键
- `Ctrl+Alt+A` - 全局截图快捷键

```typescript
// 新增方法：通过 userId 查找用户
private findUserByUserId(userId: string): OnlineUser | undefined {
  for (const user of this.onlineUsers.values()) {
    if (user.userId === userId) {
      return user
    }
  }
  return undefined
}
```
